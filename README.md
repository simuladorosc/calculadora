## Subir a GitHub Pages

1. Crear repo en GitHub y subir esta carpeta (index.html en la raíz).
2. Settings > Pages > Source: "Deploy from a branch" > main / (root).
3. Queda en https://laca06102005-bit.github.io/NOMBRE_REPO/
